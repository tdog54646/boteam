# BoTeam 实现计划
对应 [产品规格](../specs/2026-11-20-boteam-design.md)。

1. 主进程以 SQLite 事务保存元数据，建立账号唯一键、成员关系、任务与原生线程键。用临时数据库验证重复导入、双账号派发、拒绝越权接收人、审批及重启续聊。
2. 单独实现 Codex、Claude Code 和 Antigravity 的发现、导入、登录与执行入口。适配器测试覆盖身份漂移、继承的 API 环境和不安全的共享登录。原生探测只输出脱敏结论。
3. 通过沙盒渲染进程与白名单 IPC 接入首次导入、账号和 Bot 管理、会话与收件人选择。在真实 Electron 窗口验证布局与交互。
4. 构建本机可打开的应用，运行测试并记录各工具实测矩阵、启动方式和需用户真实订阅完成的步骤。
