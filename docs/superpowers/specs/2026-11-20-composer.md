# 聊天输入框

仿照用户提供的 Codex 桌面截图，输入区在上，操作栏在下。左侧放添加文件或内容及权限，右侧依次放上下文圆环、额度圆环、模型与思考强度、发送或停止。群聊保留点名与接收人选择。

文件通过本机选择或拖放添加，文字片段可以直接粘贴。发送前可以移除，发出后随消息保留本地快照。仅指定的成员收到该消息与附件。开始执行时使用发送时保存的选项，即使上一条任务仍在排队。

模型和思考强度取自绑定账号的原生选项目录。会话可覆盖 Bot 的默认设置，群聊按成员编辑，互不影响。权限同样按会话和成员保存，只展示对应工具实际支持的模式。默认延续原有审批行为。

上下文用各原生线程最后报告的实际占用与窗口容量。额度以绑定账号原生服务返回的数据为准，区分模型专属与订阅共享。额度内圈显示五小时剩余比例、外圈显示一周剩余比例；仅有周额度时显示单圈。悬停、键盘聚焦或点击查看数值、重置时间及数据来源，群聊逐成员展示。缺失数据明确标示，过期窗口不再作为当前额度。

验收覆盖旧库迁移、会话和成员隔离、排队任务设置、附件单独发送与恢复、权限在原生调用中生效、指标在重启后保留，以及截图所示控件在桌面窗口的操作和布局。

## Codex 模型与思考强度选择器

同一账号的模型目录和实际执行均使用同一个官方 Codex 运行程序。在 macOS 同时安装独立 CLI 和桌面版的情况下，识别桌面端捆绑的官方运行程序及其版本。升级时保留账号身份、权限和原会话。模型名称与强度根据原生目录生成，隐藏模型遵从原生可见性。

点击输入框中的模型与强度后弹出紧凑面板，上排显示当前强度、模型菜单入口及恢复默认按钮，下排滑杆按原生可选档位吸附。普通档位使用单色填充，仅到最高可选档位时显示彩色渐变，拖动时实时预览。点击模型打开推荐模型的可滚动列表，当前项带勾。模型和强度当场生效，键盘可操作。在群聊中选择的目标成员、未设置会话覆盖时的 Bot 默认值，以及各厂商不同的模型能力都继续生效。

上下文面板和输入栏使用同一成员的有效模型名称。圆环只展示此会话、此成员和当前模型匹配的最近一次原生读数。切换模型后，在新模型报告用量前显示等待读数。可以展开查看上一次原生记录的模型、tokens 和时间；没有模型标识的旧记录标注为未知。

## 添加面板和审批菜单

加号在输入框正上方打开等宽的分组列表，支持鼠标和键盘。用户可以选择文件与文件夹、粘贴文字或编辑器选区、绘制并附加草图。发送时提交已选附件的本地快照。文件夹须显示快照范围，让用户能在发送前核对。直接连接编辑器、录屏、原生计划、目标、技能与插件等入口以当前绑定工具实际暴露的接口为依据。

审批菜单紧贴权限按钮，每项包含图标、名称、说明及选中标记。Codex 支持时提供请求批准、原生自动审查及完全访问，保留既有的只读选项。权限、计划和选中的扩展应落实到同一账号的原生线程。群聊须明确操作所属成员，并分别保存设置。原生目标可查看、设置和清除。扩展仅接受当前账号和工作目录发现的可用项。

验收包括实际桌面窗口中的两种菜单、目录与草图发送、原生审批和计划参数、目标的线程关联、扩展按接收人成员投递，以及旧记录升级。

## 按原生工具生成斜杠菜单

在输入框开头键入 `/` 时，在输入框上方打开可滚动的命令列表，每行显示命令名和用途。继续输入可按命令或说明筛选，方向键定位，Enter 或点击选择，Esc 关闭。路径、网址、普通行文和中文输入法确认不应误触发。需要参数的命令先进入草稿，用户确认发送时执行。

命令来源按 Bot、绑定账号及当前工作目录区分。Antigravity 读取 ACP 会话公布的命令，Claude Code 读取当前 CLI 初始化结果，Codex 通过 app-server 提供的原生能力与已启用扩展生成菜单。交互命令可打开已有的权限、用量、模型或目标控件。未提供给当前运行接口的桌面功能不应显示为可执行。群聊指定命令所属成员，切换时丢弃过期的目录响应；执行前重新核验原生身份及所选命令。普通消息、附件、@ 点名和各成员的会话关联继续可用。

Codex 的 `/fork` 从选中成员已存在的原生线程创建独立私聊。分支继承该成员截至创建时的上下文、工作目录和会话设置，在自己的账号会话目录继续执行。分支保留查看原会话的入口。验收须覆盖进程重启后的续聊和原线程与分支独立推进。
