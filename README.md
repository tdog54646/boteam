# BoTeam

BoTeam 是本地优先的 macOS 订阅 Bot 工作台。给一个具体订阅账号创建 Bot，就可以单独聊天，或在项目群中点名分配任务。原生工具负责模型访问、文件操作和命令执行。应用通过本地进程与它通信。

## 打开与开始使用

在 Apple Silicon Mac 上双击本项目交付的 `release/BoTeam-darwin-arm64/BoTeam.app`。本机版本采用本地临时签名。

1. 首次启动时核对检测到的身份、登录来源和运行状态。勾选账号并点击「导入并继续」。其他已登录配置可以通过「选择其他配置目录」检测。
2. 为第一个 Bot 命名，在「模型」和「推理强度」中选择该账号原生工具列出的选项，也可以沿用原生默认。可选工作目录，最后点击「创建并开始聊天」。
3. 在「账号管理」添加第二个订阅，或从原生配置目录导入。首次启动就能检测已安装的 Antigravity 桌面端和 `agy` 配置，每行显示实际来源路径。个人 CLI 配置的文件登录通过原生核验后可直接勾选导入。桌面端使用系统共享登录时，在该行通过 Google 授权绑定账号。只有桌面端时，可先点击「安装官方 agy」，向导会在安装完成后重新检测。再次导入同一账号会更新原绑定。
4. 在「Bot 管理」创建更多 Bot。通过侧栏「新建私聊」与同一个 Bot 开启另一个独立上下文，或从群聊旁的加号选择成员。群内支持一个或多个 `@名字`、明确选择接收人和 `@全体`。同名成员可依据账号备注选择。
5. 展开回复下方的任务状态，查看实际原生工具、核验身份、工具操作与审批结果。每位接收人拥有独立的运行状态。在「Bot 管理」编辑模型和推理强度后，下一条私聊或群任务就会使用新的选择。工作目录在创建原生会话时确定。

在项目群里，可以先让 Codex 提方案，再点名另一位成员评审。被点名的成员在自己的原生会话里收到本群已发布的相关对话；长群聊优先携带近期原文。想指定某段话时，把鼠标移到消息上或用键盘聚焦「引用」，再点名接收人。即使对方的原生会话已经压缩，本轮也会重新带上引用原文。多人同时被点名时，并行读取发送时的同一份群记录。

## 项目与聊天标题

- 首页和新聊天的输入框上方都有项目选择器。发送首条消息前，可以搜索并选择已有项目、从本地文件夹新建项目，或选择「不在项目中工作」。选择项目后，Bot 使用项目的主要文件夹。选择「不在项目中工作」会沿用 Bot 的默认工作目录。
- 点击侧栏「项目」旁的文件夹加号，选择本地文件夹并导入。悬停在项目上可查看聊天数和源文件夹。点击项目行的「…」或右键项目，可置顶、编辑、移入分区、在 Finder 中显示、归档项目聊天或移除项目。「编辑」支持改名、添加和移除源文件夹，以及更换主要文件夹。
- 点击项目行右侧的铅笔，选择私聊 Bot 或群成员。新聊天会使用项目当前的主要文件夹，群聊名称由首条消息生成。导入时，已有聊天的工作目录都属于所选来源，且尚未手动归类时，会归入该项目。右键聊天也可「移至项目」。移动聊天只改变侧栏归属，原生会话继续使用创建时的工作目录。移除项目后，对话和本地文件均保留。
- 在侧栏顶部可以搜索聊天名称或消息，筛选未读和进行中的聊天，或切换分项目与合并显示。「最近聊天选项」可以切换归档状态、包含项目聊天，并按创建时间或最近更新时间排序。
- 新聊天发送首条普通消息后会获得标题。BoTeam 先从首条请求提取简短主题，纯附件消息使用文件名。所用原生工具提供会话标题时再采用原生结果。手动命名的聊天保留原名，已有聊天也可在「重命名」里选择「根据首条消息生成」，预览后保存。

## 聊天操作

- 在侧栏右键点击要整理的对话，可以重命名、置顶、标记未读，或移入自定义分区。鼠标移到对话行上可直接置顶和归档。在「已归档」中可恢复对话；选择「永久删除」需确认，删除范围为该聊天在 BoTeam 中的记录及其独占的附件快照。
- 「复制」可取得聊天的 Markdown、会话 ID、工作目录或本机聊天链接。Markdown 包含发言人、群内点名、引用和附件名。用「分享」可通过 macOS 分享菜单发送聊天文本。「打开方式」支持独立聊天窗口，也可用访达、终端或已安装的编辑器打开工作目录。

## 聊天输入框

已有可用 Bot 时，重开应用直接回到聊天输入框。上次停在管理页时会回到最近查看的可用会话。

- 点击加号，在输入框上方的面板中选择文件和文件夹、粘贴编辑器选区，或绘制草图。也可以从 Finder 拖入文件夹、直接粘贴图片。图片显示缩略图，目录显示文件数量与跳过项。发送后保存本地快照。
- 在同一面板开启计划模式，或选择当前成员原生工具提供的技能、插件和应用。Codex 可以设置持续目标，开始后可在聊天中查看进展、回答问题或停止任务。打开「目标」可读回原生状态、暂停或清除。群聊按成员分配扩展。
- 在输入框开头键入 `/` 可查看当前 Bot 的原生快捷命令。输入名称或说明筛选，用方向键定位，按 Enter 选择，按 Esc 收起。模型、权限、用量等命令直接打开对应面板，任务命令可先补充参数再发送。群内先选择一位成员，菜单会按这位成员的工具、账号和工作目录更新。
- 在输入栏点击当前权限。Codex 的「请求批准」「帮我批准」「完全访问权限」分别使用原生人工审批、自动审查和完全访问模式，「了解更多」中可切换只读。Claude 和 Antigravity 显示各自工具提供的权限。
- 点击权限名称可调整当前会话的权限。点右下角的模型名称打开思考强度滑杆，点面板中的模型名可以展开列表。点击模型或松开滑杆即保存，右上角的重置按钮恢复 Bot 默认设置。群聊可以在面板内切换成员，分别设置。
- macOS 已安装官方 Codex 桌面端时，BoTeam 通过桌面端捆绑的 Codex 程序读取该账号的模型目录并执行任务。已有账号随应用启动更新运行程序，账号绑定和原生会话保留。仅安装独立 CLI 时，模型目录来自该 CLI。
- 将指针移到上下文圆环，或使用键盘聚焦，查看当前成员在这次会话中已用的 tokens 和原生窗口容量。旁边的额度圆环以剩余比例绘制，内圈为 5 小时、外圈为每周。只有周窗口时显示单圈。详情提供重置时间与最近一次原生读数，账号共享的额度会注明范围。
- 执行期间仍可给群内其他成员派活，或者将下一条消息排队。停止按钮会取消当前对话的待执行任务和正在运行的任务，也可在任务行单独停止某一位成员。

## 本机验证范围

Codex Pro 已完成真实私聊、同一订阅下的双 Bot 群任务并发、原生文件读写、权限拒绝与允许，以及重启续聊和更换模型。Google AI Pro 已用 Antigravity 完成私聊、与 Codex 在同一群中分别接受点名，以及重启后从原生线程取回上文。Claude Code 已核验原生模型和推理强度设置，真实订阅对话仍待验收。逐项结果见[验收记录](docs/acceptance.md)。

## 从源码运行

需要 Node.js 24 或更新版本，以及希望使用的官方工具。项目以当前本机的 macOS arm64 为构建和验收平台。

```sh
npm ci
npm start
```

`npm test` 运行离线回归测试。`npm run verify:desktop` 打开临时数据目录中的真实桌面窗口，验证首次启动、跳过向导和重启。`npm run package` 在 `release/` 生成可独立打开的应用。如果打包时 BoTeam 已经打开，等当前任务结束后按 ⌘Q 退出，再打开新包。仅重新双击会唤回原进程，群聊功能更新和旧消息迁移要在新版启动后才会生效。

已登录可用 Codex 订阅的开发者还可以运行以下验收。它会在界面为 Bot 选择原生模型和推理强度，使用订阅发送两条短消息，并在中间退出、重启应用。验收检查原生工具确认的设置、实际账号及上文回忆，最后清理临时数据。

```sh
npm run verify:desktop -- --live-codex
```

Antigravity 的个人 Google 订阅在 BoTeam 中变为「可运行」后，运行 `node scripts/verify-antigravity.mjs --live` 可验收私聊、群里分别点名和重启续聊。脚本复用已授权的原生工具，在临时工作台发送真实短消息。若有多个可运行的 Google 账号，使用 `--account-id` 指定其中一个。

## 数据与账号绑定

- macOS 默认数据目录为 `~/Library/Application Support/BoTeam/`。SQLite 保存账号元数据、Bot、群成员、消息、任务和原生线程关联。原生会话与应用创建的授权目录位于独立 profile 下。退出时停止进行中的任务，重启后可以手动继续。
- Codex 文件登录按用户及工作区识别。每个「聊天 × Bot」拥有自己的 `CODEX_HOME`，执行前确认官方服务、有效身份与套餐。外部配置的访问凭据仅用于该原生进程的临时授权。外部凭据过期时由原客户端刷新，或在 BoTeam 重新授权。能取得官方限额时，详情同时显示剩余比例、重置时间及检测时间。
- Claude Code 通过原生 CLI 读取可识别身份，独立目录的订阅授权通过后才允许执行。需要同时匹配原生账号、订阅和运行进程。旧的外部配置含服务地址覆盖、缺少可验证身份或登录方式不适用时，界面显示原因。
- Antigravity 通过官方 `agy acp` 运行。每个个人 Google 订阅使用独立的原生运行目录。启动任务前核对原生状态栏报告的邮箱与套餐，以及 ACP 会话报告的订阅等级。macOS 运行策略隔开共享钥匙串与其他账号的授权目录。向导可将通过 Google 签名核验的官方 CLI 安装到 `~/.local/bin/agy`。[Google 的 CLI 安装说明](https://antigravity.google/docs/getting-started/#download-and-install)
- Bot 与账号绑定固定，账号错误不会触发自动换号。移除前会显示绑定影响，已有消息保留。工具权限按原生请求逐次处理。API Key Bot 仅在代码中保留扩展点。
